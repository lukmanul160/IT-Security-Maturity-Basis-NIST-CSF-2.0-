# Catatan terkait pada Policy Register

Buka **Policy Register → New policy / Edit → Related Knowledge Vault**.
Cari berdasarkan judul, folder, atau isi catatan, lalu centang catatan/file
Markdown yang mendukung kebijakan dan simpan policy. Hapus centang untuk
melepas hubungan. Satu catatan bisa digunakan oleh beberapa policy.

Catatan ditampilkan dalam pohon folder. Centang checkbox folder untuk
memilih seluruh catatan yang saat ini ada di dalamnya, termasuk subfolder;
hapus centang untuk melepas seluruh pilihan tersebut. Angka pada folder
menunjukkan jumlah terpilih/total. Checkbox dengan tanda sebagian berarti
baru beberapa catatan dipilih. Saat pencarian menyembunyikan sebagian
catatan, checkbox folder tetap memilih seluruh isi folder. Catatan baru
yang ditambahkan kemudian perlu dipilih dan disimpan kembali pada policy.

Tautan catatan muncul di bawah judul kebijakan pada tabel. Klik tautan untuk
membuka catatan dan mengakses referensi file yang ada di dalamnya.
Pencarian Policy Register mencakup isi, judul, dan folder catatan yang
ditautkan, serta detail kebijakan dan nama lampiran. Filter kategori,
status, dan owner tetap berlaku bersama pencarian.

Pemilihan dan pencarian isi catatan memerlukan izin baca Knowledge Notes.
Isi terbaru dimuat saat membuka Policy Register atau form policy. Hubungan
memakai ID sehingga perubahan judul atau folder tidak memutus tautan.
Catatan yang sudah dihapus ditampilkan sebagai belum tersedia pada form;
hapus centang untuk membersihkan hubungan tersebut.

Kolom hubungan ditambahkan otomatis saat server dimulai. Pencarian ini
membaca isi catatan Knowledge Vault; isi PDF/Word pada lampiran belum
diekstrak untuk pencarian.

Pemilih file existing pada CSF, Privacy, ISO 27001/SOA dan Audit Finding
mencari nama/jalur file, judul/detail/catatan policy, serta judul, folder,
dan isi Knowledge Vault yang ditautkan pada policy pemilik lampiran.
Hasil menampilkan cuplikan sumber yang cocok. File tanpa hubungan policy
tetap dapat dicari berdasarkan nama/jalur. Isi Vault hanya disertakan
bila pengguna mempunyai izin baca Knowledge Notes.
